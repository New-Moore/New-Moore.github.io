Suspense & ckboomc

Home page of the Suspense and ckboomc apps, built on AutoVideo.

AutoVideo is a private tool that publishes new videos every day to two YouTube channels run by the same owner. Each channel has its own app:

Suspense

Publishes original stories, facts and cartoon street interviews to the YouTube channel Suspense (@suspensetw).

ckboomc

Publishes Traditional Chinese Shorts — fast-paced fact lists, AI model usage rankings and daily GitHub trending projects — to the YouTube channel ckboomc (@ckboomc).

Both apps use the YouTube Data API only to upload videos and manage playlists and thumbnails on the channel owner's own channels. They are not offered to other users.
